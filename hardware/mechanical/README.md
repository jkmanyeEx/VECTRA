# Mechanical configuration

Store non-sensitive geometry measurements and revision notes here.

For each cant configuration, record:

- nominal angle and cant convention;
- measured angle for each motor;
- motor center position relative to the center of mass;
- rotor-axis unit vectors in the body frame;
- motor spin direction;
- mount revision and measurement uncertainty;
- whether mass, center of mass, or inertia changed.

CAD source files may be referenced from this document but should not be copied
into the repository without confirming size and licensing.
