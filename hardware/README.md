# Hardware integration

Hardware documents and configuration snapshots live here; runtime recordings
belong in `data/raw`.

- `pixhawk`: PX4 parameter exports, interface maps, and safety checklists.
- `sensors`: external wind, RPM, voltage, and current sensor specifications.
- `mechanical`: motor positions, measured cant angles, center-of-mass records,
  and geometry revision evidence.

No secrets, radio identifiers, private keys, or sensitive device metadata may
be committed.
